This R code is part of a larger study examining the effect of the CRKN-Wiley Transformative Agreement at the University of Saskatchewan.

WileyHybridEligibile20232025ISSNQuery.R: Code that queries the OpenAlex API to retrieve a list of hybrid journals eligible for APC waivers under the CRKN-Wiley Transformative agreement from 2023 to 2025 based on ISSNs.

WileyNonWoSOpenAlexRORQuery.R: Code that queries the OpenAlex API to retrieve works metadata within hybrid journals eligible for APC waivers under the CRKN-Wiley Transformative agreement from 2023 to 2025 for Queen's University, University of Guelph and University of Saskatchewan for journals not indexed by Web of Science. The query includes works from 2020-2025.

WileyWoSOpenAlexDOIQuery.R: Code that queries the OpenAlex API to retrieve works metadata based on DOI for a dataset of works (2020-2025) derived from a Web of Science query for works published by authors affiliated with Queen's University, University of Guelph and University of Saskatchewan in hybrid journals eligible for APC waivers under the CRKN-Wiley Transformative agreement from 2023 to 2025.
